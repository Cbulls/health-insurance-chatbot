# 두 유형 증상 분석용 공공의료데이터

증상 칩을 **자주 느끼는 불편**과 **놓치기 쉬운 불편**으로 나누는 근거는 LLM이 아니라 KB 큐레이션(질병관리청 국가건강정보포털 개요)이다. 공공데이터는 그 분류를 **통계·규모로 검증·설명**할 때 붙인다. 확진·추천이 아니다.

면담 정리와 같은 맥락: [PROFESSOR_FEEDBACK_OCT20.md](PROFESSOR_FEEDBACK_OCT20.md).

## RESULT 근거 사슬 (A–E)

| 블록 | 내용 | 데이터 | LLM |
|------|------|--------|-----|
| **A 입력 확인** | 선택 증상·상황 메아리 | profile | 사용 안 함 |
| **B 염두 영역 카드** | 연결 증상·후보·흔함·심각도·이용/비용·직군 | `areas_catalog` + HIRA + **KOSIS 캐시** + 직군 crosswalk | 숫자·라벨 변조 금지 |
| **C 보험 연결** | 외래/입원/상해/정액 + 수술·비용구간 보조 | coverages + KOSIS 수술·A054 | 상품명 금지 |
| **D 추가 질문** | 지속기간·직군세분·기존실손 (정적) | — | — |
| **E 안전·면책** | 비진단·응급 신호 | disclaimer + care_hint | — |
| **접힘** | 의료급여 수술 통계 · 구 브리프·KCD/포털 | KOSIS A002 등 | 실손과 혼동 금지 |

추적 경로: **선택 증상 ↔ areas_catalog ↔ HIRA(KCD 흔함) ↔ KOSIS(연령·성별 이용·수술·입원) ↔ 직군(업종 산재) ↔ 보험 축**.

흔함 라벨: 매칭된 영역 카드들의 닫힌 KCD 집합 안에서 `age_sex_count` 상대 순위. 상위 20% `흔한 편` / 20–70% `보통` / 하위 30% `드문 편`. 집합 2개 미만이면 `찾지 못했어요`.

### UI 연령·직업 (세분 ≠ 통계 키)

- **연령 UI:** `0-4` / `5-9` / 10–60대 / `70-79` / `80+` ([`age_bands.py`](../src/harag/guidance/age_bands.py)).
- **HIRA 조회:** `0-4`·`5-9` → `0-9`, `70-79`·`80+` → `70+` (캐시는 10년 키만).
- **KOSIS 조회:** UI 밴드별 5세 라벨 목록으로 합산.
- **직업군:** 사무·관리 / 고객응대·판매·요식 / 현장·운전·배달 / 의료·돌봄 / 교육·연구 / 가사·육아 / 은퇴·무직 / 학생 / 기타. 산재(N034)는 업종 근사 crosswalk; 가사·은퇴·학생은 통계 미연결.

## 저장 계층 (통계 ≠ Qdrant)

1. **스냅샷 JSON** `src/harag/guidance/kosis_cache/{tblId}/latest.json` — 진실의 원천, 시연 안정
2. **SQLite `stat_fact`** `./data/guidance_stats.db` (`GUIDANCE_STATS_DSN`) — `get_stat(metric, dims)` 키 조회
3. **템플릿/라벨** — LLM은 숫자 창작·재계산 금지

동기화: `KOSIS_API_KEY=... python -m harag.guidance.kosis_nhis`  
`guide()` 중 OpenAPI 호출 없음. **채팅·URL·커밋에 API 키를 넣지 말 것.** 키가 노출되면 KOSIS에서 재발급.

출처 UI: **`KOSIS · 국민건강보험공단, {연도}`** / **`KOSIS · 고용노동부, {표명}, {연도} · 규모 전체`**

앱 `20-29` → KOSIS `20-24`+`25-29` 합산. A043/A047으로 「이 병 확률」을 만들지 않는다.

A0611 동기화는 **연령·입원외래=ALL**(원 URL의 0~9세만이면 성인 불가). 질병 코드는 닫힌 목록. 진료실인원은 질병군 간 중복 가능 → 합산 금지. HIRA KCD 흔함과 별개 보조 슬롯(`disease_298`).

### 직군 crosswalk

`occupation_crosswalk.yaml` — 칩(`field`/`office`/`service`) → 업종 라벨(근사).  
N034는 **질병 유형·직종이 아니라 업종×사업장 규모** 표이므로 규모 입력 없이 `size=전체`만 쓰고, UI에 근사·승인 건수(≠발생률)를 고지한다.

**폐기:** 『한국의 사회동향 2012』 건강 장 — 적재·인용하지 않음.

## 쓰지 않는 것

- 사용자 자유문을 공공 API에 보내는 것
- `guide()` 중 KOSIS/HIRA 실시간 대량 호출로 숫자를 새로 만드는 것
- 공공 통계를 진단·유병률·전조·개인 확률로 표시하는 것
- 의료급여 수치를 건강보험·실손 문장에 암묵 혼입
- 통계 표를 Qdrant 임베딩으로 “검색”하는 것
- 규모별 통계를 규모 입력 없이 구간별로 연결하는 것
- 2012 사회동향 등 시효 지난 사회지표를 결과 정본으로 쓰는 것
